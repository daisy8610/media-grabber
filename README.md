# 媒體連結下載器

一個瀏覽器書籤小工具(bookmarklet),在 X、Instagram、Threads 的貼文頁面點一下,就會列出該貼文的圖片與影片原始連結,右鍵即可另存。

不需要安裝擴充功能、不需要終端機、不需要登入任何第三方服務。整包就是一個 HTML 檔案。

---

## 安裝

1. 開啟 https://daisy8610.github.io/media-grabber/
2. 顯示書籤列(macOS Chrome:`Cmd+Shift+B`)
3. 把頁面上的黑色按鈕「📎 抓媒體」拖曳到書籤列

拖曳失敗時(部分瀏覽器不支援),改用頁面上的「複製程式碼」按鈕,再手動新增一個書籤、把程式碼貼進網址欄。

> 書籤裡存的是整段程式碼的副本,安裝後就算網頁打不開,書籤照樣能用。反過來說,工具有更新時舊書籤不會跟著變,要刪掉舊書籤、重新拖一次。更新內容見 [CHANGELOG.md](CHANGELOG.md)。

## 使用方式

三個平台的流程不同,因為各自的技術限制不一樣。

### X(Twitter)

1. 在單則貼文頁面點書籤 → 會自動開啟一個滿是文字的資料分頁(正常現象)
2. 在那個分頁**再點一次書籤** → 跳出清單,自動選最高畫質的 mp4

### Instagram 圖片

1. 在單獨分頁打開貼文,不要往下滑
2. 點書籤,面板跳出來
3. **面板開著,直接左右切過每一張輪播圖**,清單會即時累加
4. 想要原始畫質就先點圖放大,清單會自動把小圖換成大圖

### Instagram 影片

1. 在貼文網址後面加上 `embed/`,例如 `instagram.com/p/XXXXXX/embed/`
   (或直接點圖片面板上的黃色提示連結)
2. 在那個頁面點書籤

### Threads

1. 點進單一貼文頁面(**不要在動態牆上用**)
2. 點書籤,**面板開著切過每一張圖**
3. 大圖沒出現時,點一下「顯示全部」,再點回「只顯示貼文」

## 運作原理

### X:走公開的貼文資料介面

X 的影片是 HLS 串流播放,頁面上只有一個 `blob:` 暫存位址,不是完整檔案,直接抓會拿到空檔。

解法是改用 `cdn.syndication.twimg.com/tweet-result`(X 提供給外部網站內嵌貼文用的公開資料介面),從貼文 ID 推算 token 後查詢,回傳的 JSON 裡有各畫質的真實 mp4 網址與原圖網址。

這個介面不允許瀏覽器端程式讀取(沒有 CORS 標頭),但**直接開啟網址**不受限制,這就是 X 需要點兩次的原因:第一次開資料分頁,第二次在那個分頁上解析。瀏覽器的安全機制不允許原分頁伸手讀取新分頁的內容,中間必須有一次人為操作。

### Instagram:圖片與影片分兩個頁面抓

- **影片**:一般貼文頁的影片同樣是串流播放,抓不到完整檔案。只有 `/embed/` 頁面(給外部網站內嵌用)會直接載入完整的 mp4。
- **圖片**:`/embed/` 頁面只載入第一張圖,輪播的後續圖片抓不到,所以圖片必須留在貼文頁抓。
- **輪播**:IG 為了省記憶體,切到第 3 張時會把第 1 張從頁面移除。所以採用**累積式收集**:面板開著的期間持續監看頁面變化,切過的每一張都會被記錄下來。

### 影片縮圖:從影片本身擷取

早期版本試過用「畫面位置最接近」來替影片配對縮圖,但水平輪播時會整組錯位。

現在改成建立一個隱藏的播放器載入該支影片、跳到第 0.5 秒、把那一格畫面畫進 canvas 轉成縮圖。因為圖片直接來自影片本身,結構上不可能配錯。

### 同檔名自動合併

同一張圖片的不同尺寸版本在 CDN 上**檔名相同、只有查詢參數不同**。工具以檔名為識別,只保留解析度最大的版本,所以點圖放大後,清單裡的小圖會自動被原圖取代。

清單每一項右下角會顯示實際像素寬度,方便判斷拿到的是不是原圖。

## 已知限制

- **連結有時效性**:IG/Threads 的媒體網址帶有簽章,抓到請盡快下載
- **私密或已刪除的貼文抓不到**
- **雜訊**:Threads 找不到貼文區塊時會改掃整頁,這時清單可能混入其他貼文的媒體,請靠「顯示全部 / 只顯示貼文」切換自行挑選
- **手機不能用**:版面與判斷邏輯都是照電腦版寫的,且 IG/Threads 在手機上多半是用 App 開啟
- **平台改版可能失效**:判斷條件依賴各平台的頁面結構,改版時需要調整

## 平台支援狀況

| 平台 | 圖片 | 影片 | 點擊次數 |
|---|---|---|---|
| X | 原始畫質 | 最高畫質 mp4 | 2 |
| Instagram | 累積式輪播,自動升級原圖 | 需走 `/embed/` 頁 | 1 + 1 |
| Threads | 可抓 | 可抓,縮圖正確 | 1(大圖沒出現時切換一次顯示模式) |
